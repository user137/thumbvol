# thumbvol

*[English version](README.md)*

Легкий демон, що перетворює бічне колесо великого пальця Logitech MX Master на регулятор
гучності (Windows та Linux) — крихітна заміна Logi Options/Options+ заради єдиної фічі, яка
справді потрібна.

## Навіщо

Logi Options/Options+ — важкий, глючний, витікає пам'яттю, і весь цей комбайн потрібен заради
однієї речі: бічне колесо великого пальця мало б крутити гучність. `thumbvol` робить лише це.
Встановив — забув: автостарт з ОС, без фонового телеметричного трафіку.

## Що робить

- Бічне колесо (thumb wheel) → гучність системи, з нативним OSD-індикатором Windows/DE.
- Автостарт з ОС (можна вимкнути в конфізі).
- **Windows:** подія колеса глушиться, тому вона *не* додатково скролить активне вікно вбік.
  Трей-іконка з меню:
  - **Sensitivity** (підменю, 1–5) і **Invert direction** (чекбокс) — застосовуються одразу й
    записуються в конфіг-файл, переживають рестарт;
  - **Reload** — перечитати конфіг-файл з диска вручну;
  - **About**, **Exit**.
- **Linux:** подія колеса **не** глушиться (лишається звичайним горизонтальним скролом на додачу
  до зміни гучності) — свідоме спрощення v1, причина в [DECISIONS.md](DECISIONS.md) (D1). Без
  трею — лише конфіг-файл (D8).

Все інше (DPI, жести, профілі по застосунках, інші кнопки) — свідомо поза межами v1, див.
[TASKS.md](TASKS.md).

## Встановлення з пакунка (рекомендовано)

Готові пакунки — MSI (Windows) і `.deb` (Linux) — публікуються на сторінці
[Releases](https://github.com/user137/thumbvol/releases) кожного тегованого релізу.

- **Windows:** запустити `.msi`. Встановлення без прав адміністратора (per-user, у
  `%LocalAppData%\thumbvol\`) — UAC не спливе. На завершальному екрані є галочка "Launch
  thumbvol", яка одразу її й запускає (перший запуск сам реєструє автостарт).
- **Linux:** `sudo dpkg -i thumbvol_*.deb` (або `apt install ./thumbvol_*.deb`, якщо потрібно
  автоматично підтягнути залежності). Встановлює в `/usr/bin/thumbvol`; права на
  `/dev/input`/`/dev/uinput` — як описано нижче.

**Перед видаленням пакунка** виконати `thumbvol --uninstall-autostart` — деінсталятор (і MSI, і
`dpkg -r`) прибирає лише самі файли, а не запис автозапуску: той пишеться самою програмою під час
першого запуску (`HKCU\...\Run` / `~/.config/autostart/thumbvol.desktop`), інсталятор про нього
не знає. Без цього кроку ОС спробує запустити вже видалений бінарник при наступному вході —
мовчки, без помітної для користувача помилки.

## Встановлення з джерельного коду

Потрібен [Rust](https://rustup.rs/) (stable).

```sh
git clone <URL цього репозиторію>
cd thumbvol
cargo build --release
```

Бінарник — `target/release/thumbvol` (`.exe` на Windows, ~500 КБ, без рантайм-залежностей).
Перенести його в постійне місце
(наприклад, `%LOCALAPPDATA%\thumbvol\` на Windows чи `~/.local/bin/` на Linux) **до** першого
запуску — автостарт реєструє поточний шлях до exe, і якщо файл потім пересунути чи видалити,
запис в автозапуску мовчки зламається.

Перший запуск сам зареєструє автостарт (якщо `general.autostart = true`, дефолт) і почне слухати
бічне колесо. Без консольного вікна на Windows.

### Linux: права на пристрій

Потрібен доступ на читання `/dev/input/eventN` (миша) і на запис `/dev/uinput` (емуляція клавіш
гучності) — типово через групи `input`/`uinput`:

```sh
sudo usermod -aG input,uinput "$USER"
# перелогінитись, щоб membership застосувався
```

Якщо автовизначення пристрою (перший з `REL_HWHEEL`) знаходить не ту мишу — задати шлях явно в
конфізі (`[linux] device_path`, див. нижче).

## Конфіг (необов'язковий)

Копія [`config.example.toml`](config.example.toml) з коментарями до кожного поля. Розташування:

- Windows: `%APPDATA%\thumbvol\config.toml`
- Linux: `$XDG_CONFIG_HOME/thumbvol/config.toml` (типово `~/.config/thumbvol/config.toml`)

Без файлу — дефолти: чутливість `2`, без реверсу, автостарт увімкнено.

Зміна конфігу текстовим редактором вимагає перезапуску процесу або **Reload** з трей-меню
(Windows); на Linux — лише перезапуску (гарячого перечитування без трею немає). Invert і
Sensitivity, змінені через трей-меню на Windows, застосовуються миттєво і без Reload.

**Увага:** зміна Invert чи Sensitivity з трей-меню перезаписує весь конфіг-файл — усі коментарі
(включно зі скопійованими з `config.example.toml`) при цьому губляться, лишаються тільки значення.
Якщо коментарі важливі — тримайте власну копію `config.example.toml` окремо як довідник.

Вимкнути автостарт вручну (без редагування конфігу):

```sh
thumbvol --uninstall-autostart
```
